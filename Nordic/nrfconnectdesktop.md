# nRF Connect for Desktop
 
Herramienta de Nordic Semiconductor para interactuar con dispositivos basados en chips nRF (programación, monitoreo BLE, actualización de firmware, etc.). Se distribuye como AppImage.
 
## Ubicación
 
```text
~/.local/bin/nrfconnect-5.3.2-x86_64.AppImage
```
 
## Dar permisos de ejecución (solo la primera vez)
 
```bash
chmod +x ~/.local/bin/nrfconnect-5.3.2-x86_64.AppImage
```
 
## Abrir la aplicación
 
```bash
~/.local/bin/nrfconnect-5.3.2-x86_64.AppImage
```
